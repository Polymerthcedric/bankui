# BankUI

A high-fidelity mobile banking demo that actually feels like a native app. Built with Next.js 16 and React 19, featuring simulated FaceID, multi-currency wallets, and M-Pesa integration.

## The Stance
Banking software is notoriously terrible. It's slow, ugly, and hostile to the user. BankUI is a demonstration of how financial software should feel: instantaneous, confident, and beautifully constrained. We use modern React not to add bloat, but to aggressively compress state complexity.

## Running
1. `npm install`
2. `npm run dev`
